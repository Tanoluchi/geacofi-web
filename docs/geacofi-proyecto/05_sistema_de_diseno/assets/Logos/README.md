# Logos

El lettering original "geacofi", vectorizado del logo. Nunca se reemplaza por una fuente.

- **geacofi-logo-carbon**: sobre durazno o crema.
- **geacofi-logo-crema**: sobre terracota o carbón.
- **geacofi-logo-bordo**: sobre durazno, en piezas de eventos.

Una sola tinta por archivo. Espacio libre alrededor: la altura de la "g". Tamaño mínimo: 90 px de ancho en pantalla.
