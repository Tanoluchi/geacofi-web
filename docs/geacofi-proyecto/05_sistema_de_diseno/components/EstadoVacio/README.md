# Estado vacío

Cuando no hay nada para mostrar, la rana lo dice con humor en lugar de dejar un hueco.

- Fondo `crema`, contorno `border-ink`, radio `radius-xl`, sombra `card`.
- Ilustración de la rana acorde (siesta para eventos y fuera de horario; asomándose para listas vacías) y un título en Gaegu (`h3`, color `heading`).
- Una línea de texto que explica qué hacer y un solo botón con la salida (por ejemplo, seguir en Instagram).
- Variante de carga: la rana moliendo con "moliendo…" en Gaegu, con la manija animada.
- Variante de confirmación: tira carbón con la rana guiñando y "¡listo! te respondemos pronto", `role="status"`.
