# Ticket de visita

La tarjeta de "cómo llegar": dirección, horarios y acciones, con lugar para el mapa.

- Fondo `crema`, contorno `border-ink`, radio `radius-xl`, sombra dura `card` más grande (10 px).
- Izquierda: etiqueta "pasá cuando quieras", dirección en Gaegu (`h2`), ciudad en Barlow Condensed, horarios en pastillas carbón con DM Mono, y dos botones: escribinos (principal) y cómo llegar (secundario).
- Derecha: el mapa, separado por una línea punteada como un talón. Se carga recién al llegar a la sección.
- La rana saludando puede asomarse por arriba a la derecha.
- Datos: `local.json`.
