# Tarjeta de carta

Una categoría de la carta presentada como la lista de temas de un disco: número de pista, nombre, descripción y precio.

- Fondo `surface-raised`, contorno `border-ink` en `border`, radio `radius-lg`, sombra `card`. En tema *Noche* la sombra pasa a `card-noche`.
- Encabezado: disco con la letra del lado (A, B, C o + para bonus track), etiqueta en mono y nombre en Barlow Condensed (`card-title`).
- Filas: número en mono `terracota` (`ambar` de noche), nombre en `item`, descripción en `small` con `ink-muted`, precio en `price` con cifras tabulares.
- Separadores punteados de `border-dash`. El último ítem no lleva separador.
- Datos: una categoría de `carta.json`.
